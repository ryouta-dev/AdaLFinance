# ADAL FINANCE 360 AI

Двуязычная учебная платформа для колледжей. В ADAL City представлены семь виртуальных предприятий. У каждого есть рабочий кейс с документами и проверкой решений. Преподаватель видит ответы и исправления участников своей группы.

## Запуск

Нужен Node.js 24 или новее.

~~~powershell
Set-Location AdaLFinance
npm ci
npm start
~~~

Откройте [тренажёр](http://127.0.0.1:3600). Локальные попытки хранятся в `.data/adal.sqlite`. Можно задать другой файл через `ADAL_DB` и порт через `PORT`. Чтобы проверить вход по QR с телефона в одной доверенной сети, задайте `ADAL_HOST=0.0.0.0`, откройте кабинет преподавателя по сетевому IP компьютера и сгенерируйте код уже с этого адреса.

| Роль | Логин | Пароль |
| --- | --- | --- |
| Студент Аружан | `student` | `market360` |
| Студент Әли | `student2` | `team360` |
| Преподаватель | `teacher` | `adal360` |

Базу из размещённого приложения не подменяет локальная. Демо-аккаунты рассчитаны на учебные данные.

## Маршрут по полной версии

| Предприятие или раздел | Что можно сделать |
| --- | --- |
| ADAL Market | Завершить исходный кейс. При пропущенном возврате увидеть −3 500 ₸ и исправить запись. Физическая выдача остаётся одна. |
| ADAL Café | Сдать кассовую смену с проверкой сдачи, X- и Z-отчётами. В свободной кассе оформить несколько продаж и вернуть часть или все позиции по исходным чекам. |
| ADAL Factory | Оформить приход, передачу в производство и оплату поставщику. Принятые проводки формируют журнал и оборотно-сальдовую ведомость. |
| ADAL Build | Учесть рабочее событие, сверить доходы и расходы, построить отчёт о финансовом положении и проверить равенство активов, обязательств и капитала. |
| ADAL Logistics | Рассчитать НДС за III квартал 2026 года, проверить черновик декларации, исключить неподтверждённый зачёт и увидеть исправленную сумму к уплате. |
| ADAL Bank | Сверить выписку и регистр, отразить комиссию по банковскому документу. |
| ADAL Advisory | Собрать доказательства двойной оплаты и пройти этический кейс с решением по изменению даты документа и согласованным каналом эскалации. |
| ADAL Analytics | Пройти входную диагностику. Открыть портфолио, карту компетенций, историю попыток, карьерную ступень и виртуальную зарплату. |
| Кабинет преподавателя | Рассмотреть ответы и исправления, выгрузить результаты группы в CSV, выпустить версию кейса или создать одноразовый QR-вход для учащегося. |
| Команда и Кубок ADAL | Собрать общий акт инвентаризации под двумя аккаунтами. Пройти три индивидуальных раунда с таблицей группы. |

В строительном кейсе вариант рабочего события выбирается при открытии попытки и сохраняется вместе с условиями. Диагностика фиксирует по одному ответу на вопрос. Ранги продвигаются после 2, 4, 6 и 8 подтверждённых разных кейсов. Виртуальная зарплата начисляется за каждый такой кейс один раз. Для оценки результатов используются 2 балла за верный первый ответ, 1 за исправленный и 0 за оставшуюся ошибку.

## Учебные материалы и наставник

Встроенные условия, документы и ключи находятся в [каталоге](content/catalog.mjs). Исходная смена хранится в [market-v1.mjs](content/market-v1.mjs), расширенные кейсы в [lessons.mjs](content/lessons.mjs). Новая попытка получает актуальную версию для группы. Существующие попытки хранят полную копию своих условий.

В конструкторе преподавателя можно создать задачу с числовым ответом через форму на двух языках. Редактор JSON поддерживает числовые ответы, выбор, проводки и версионирование. В специализированных кассовых кейсах условия редактируются в файлах контента.

Наставник предлагает подсказки от кассира, бухгалтера, аудитора и специалиста по контролю. Встроенный разбор работает без ключа. Чтобы подключить модель через OpenAI Responses API, задайте `OPENAI_API_KEY` и `OPENAI_MODEL` в окружении сервера. Модель получает текст текущего задания, подсказку, роль и вопрос студента. Оценки определяются ключом версии кейса. Если модель недоступна, система возвращает встроенный разбор.

Первичные формы, чеки, декларация и расчёт зарплаты учебные. Для смены ADAL Market проводка `Дт 1010 / Кт 6010 / 52 400 ₸` отражает первоначальную продажу без НДС и себестоимости. В кейсе ADAL Logistics применяется базовая ставка 16%, а право на зачёт задано условиями. [Типовой план счетов РК](https://old.adilet.zan.kz/rus/docs/V070004771_). [Разъяснение КГД по НДС](https://www.gov.kz/org/kgd-astana/press/news/details/1175082?lang=ru).

## Проверки и резервная копия

~~~powershell
npm test
npm run build
~~~

Проверки покрывают обе ветки MVP, регистры и финансовый отчёт, исправление декларации, настоящие операции свободной кассы, диагностику, наставника, версии кейсов, повторные запросы, роли, командную работу и Кубок. Сборка создаёт Cloudflare Worker. Схема в `drizzle/` используется и локальным SQLite, и размещённым D1.
